# ClubOps AI ✨

> 🤖 The AI-powered operating system for modern clubs.

ClubOps AI helps student clubs, professional communities, sports organizations, and member-led groups run better—from planning events and engaging members to answering questions and understanding what needs attention next. It brings the everyday work of club operations into one thoughtful, AI-centered experience.

## Why ClubOps AI? 💡

Running a club should be about community, not chasing updates across chats, spreadsheets, and inboxes. ClubOps AI gives organizers a clearer command center and gives members faster, more helpful access to the information they need.

## What it helps with 🚀

- **AI club assistant** — Answer member questions about events, policies, memberships, and resources in natural language.
- **Event operations** — Plan, publish, promote, and keep track of club events from one place.
- **Member engagement** — Share announcements, welcome new members, and surface opportunities at the right time.
- **Smart workflows** — Turn routine work such as reminders, follow-ups, summaries, and task assignment into simple automations.
- **Club intelligence** — See participation trends, engagement signals, and useful next steps without digging through raw data.
- **One reliable home** — Keep your club’s updates, knowledge, people, and activity connected.

## Run locally 💻

This project uses static HTML/CSS/JavaScript pages with PHP for authentication and the dashboard.
### Prerequisites

1. Install a local PHP and MySQL environment, such as XAMPP, MAMP, or Laragon.
2. Import the SQL file in `database/` into MySQL.
3. Update the database credentials in `config.php` if your local setup differs.
4. Serve this folder through your local PHP server.
5. Open the local URL in your browser.
- Python 3.10 or later
- MySQL 8.0 or later
- `pip`

> Do not open the PHP pages directly from the file system—they need a PHP-enabled local server and database connection.
